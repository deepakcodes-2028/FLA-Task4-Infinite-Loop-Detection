# Reference implementation review and originality note

The team reference was the public repository `https://github.com/Vaishakkr/FLA-Task4-Infinite-Loop-Detection`, linked in the supplied sample report. Its README describes a MiniLang-to-register-machine workflow, ranking/recurrent/constant-step proof ideas, cycle-based execution, Turing-machine examples, a benchmark, and test/diagram outputs.

LoopScope uses that public project as a scope and presentation reference only. The implementation in this package is independently authored and has a different package identity, AST validation/compiler code, instruction representation, supported operator subset, static proof implementation, benchmark names and cases, Turing-machine examples, test suite, chart generation, and report text. No claim is made that the two implementations have the same source code or experimental data.

The sample report is cited in the final report as a reference for the related assignment implementation. The team should cite any additional books or papers actually consulted and should confirm that its final similarity report meets the institution's requirement.

# Experimental results

All numbers in this file are generated by `tools/run_experiments.py` in this repository.

## Benchmark

The benchmark contains 15 named MiniLoop programs covering countdown and count-up loops, wrong-direction updates, modular target reachability, unchanged counters, false initial guards, literal-true loops, repeated-state cycles, `break`, multiplicative growth, a slow but finite loop, and a non-repeating growth case.

| Metric | Result |
|---|---:|
| Programs in benchmark | 15 |
| Definite LoopScope answers | 14 |
| Correct definite answers | 14 |
| Incorrect definite answers | 0 |
| `UNKNOWN` answers | 1 |
| Timeout-only false positives | 1 (`slow_finite`) |

The one inconclusive program is `unbounded_growth`: its counter grows without bound and the current static proof templates do not cover multiplication. The interpreter reaches its instruction budget without a halt or repeated complete configuration, so it correctly abstains.

The timeout baseline uses a fixed 300-instruction cutoff and labels any run that has not finished by that point as `LOOPS_GUESS`. This policy wrongly labels `slow_finite`, even though the static ranking argument proves it terminates. This illustrates that an operational timeout is a service policy, not a proof of infinite execution.

## Generated soundness sweep

The experiment generates 2,400 single-counter programs from five guard operators (`<`, `<=`, `>`, `>=`, `!=`), bounded initial values and bounds, and constant increments. For this restricted loop grammar, an exact arithmetic oracle computes whether the target is reached. LoopScope returned a definite proof for all 2,400 generated cases; all 2,400 agreed with the oracle. This is evidence about the tested template family only, not a proof that the analyser is sound for arbitrary source programs.

## Reproducibility

Run `python tools/run_experiments.py` to regenerate the CSV files and charts. Run `python -m pytest -q` to execute the test suite. On the generation environment used for this report, the suite contains 23 passing tests.

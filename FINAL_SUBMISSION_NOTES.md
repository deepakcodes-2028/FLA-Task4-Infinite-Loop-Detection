# Before submitting

1. Confirm all three members' names and registration numbers exactly match the department records.
2. Review and update the contribution statements so they reflect the work actually completed by each member.
3. Publish the repository to the team's own GitHub account and replace the "GitHub URL to be added" placeholder in the report with the real URL.
4. Run `python -m pytest -q` and `python tools/run_experiments.py` once more on the submission machine.
5. Add any presentation or live-demonstration evidence required by the course faculty.
6. Check the final similarity report and cite every additional source the team actually consults.

The included benchmark and sweep numbers are outputs from the bundled LoopScope implementation, not values copied from the reference report.
